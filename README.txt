ICU Shift Balance - Prototype v1

طريقة التشغيل:
1) افتح index.html مباشرة على الكمبيوتر للتجربة.
2) لو أردت استخدامه كتطبيق PWA على الهاتف/التابلت، ارفعه على أي استضافة HTTPS مجانية مثل GitHub Pages أو Netlify.
3) البيانات محفوظة محليًا داخل المتصفح باستخدام localStorage.
4) الهيستوري الحالي محلي على نفس الجهاز/المتصفح ولا يزامن بين الأجهزة.

الموجود في النسخة الأولى:
- إضافة التمريض مع: جديد / متوسط / قديم / Senior Shift
- إضافة الحالات مع: مستقرة / متوسطة / خطرة / حرجة
- Respiratory support: Room air / Nasal / Facemask / Reservoir mask / Bipap / Niv / Vent
- Recommended checklist
- Rules engine مبدئي لتوزيع الحالات
- محاولة إبقاء Senior Shift فاضي إذا كان ذلك لا يحمّل باقي الاستف
- Vent = ممرض منفرد قدر الإمكان
- مراعاة الحمل الحالي + الهيستوري آخر 14 يوم
- توزيع المهام الإضافية
- Refresh للتوزيعة
- تدخل يدوي
- History بالتاريخ واليوم والشفت

تنبيه:
هذه نسخة تنظيمية تجريبية ولا تستبدل الحكم السريري أو سياسات المستشفى، خصوصًا في حالات العجز الشديد.
